# Laboratorio de Chispa ⚡

Simulador de circuitos eléctricos en 2D para el módulo de **Electrónica** del curso *Auxiliar en Informática* — Fundación Social de Desarrollo Ecuatoriano (F.S.D.E.).

- 10 piezas: pila, foco, LED, motor, timbre, interruptor, pulsador, resistencia, perilla y sensor de luz.
- Simulación real de corriente continua (el LED se quema sin resistencia, cortocircuitos, serie y paralelo).
- 18 misiones guiadas en 3 clases, con revisión automática.
- Lecciones cortas: electricidad, circuito, voltaje/corriente/resistencia, serie/paralelo, conductores, seguridad.
- Guardado automático en el navegador y descarga/apertura de archivos `.json`.
- Funciona sin internet después de la primera visita (service worker).

Sitio estático: no necesita compilación. Para probarlo en local: `npx serve .`
